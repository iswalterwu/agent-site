# WINDOW：桌面常驻工地小窗

代号：WINDOW

> **读我**：界面、楼体和结构细节见 [design.md](../design.md)；本文件只列现行的、可验证的行为要求。

## 窗口

- WINDOW-1：App 启动后贴目标屏工作区右缘，宽 520 CSS px（楼体 220 加左侧 300 的卡片位），高 `min(工作区, 720)`，上下留白相等，不盖任务栏；窗口出现在任务栏，启动不抢焦点；顶部 32 CSS px 拖动条能移动窗口。
- WINDOW-2：画布固定按 2× 放大；按设备像素重画，文字和像素画不模糊。
- WINDOW-3：楼体、气泡、灯、卡片、彩带、摘要、顶栏和齿轮可点；点击楼外天空、透明边缘和卡片外空白落到下面的窗口，不激活工地。主进程按 16 ms 轮询光标和命中矩形切换穿透，菜单打开时整窗接收鼠标。
- WINDOW-10：贴边隐藏时只剩 8 逻辑 px 彩带，窗口边界仍是 520（收起不改窗口尺寸）；悬停彩带只显示摘要，不展开；点击彩带或摘要才展开；非演示模式下新决策到达时自动展开并打开决策卡（这是唯一的自动展开例外）；指针进过整窗后，离开 3 秒自动收起（从启动起还没进过时不收）；卡片开着时不自动收（有人在等也照收，彩带闪橙色提示）；Esc 收起。把窗口拖到工作区右缘 24 px 内或已经越过右缘，松开鼠标都吸回右缘并收起（卡片先关；程序自己改窗不触发；拖动途中停顿不吸；按窗口多数所在的屏算；吸附只改位置，尺寸不变）。
- WINDOW-11：悬停彩带某段显示该 feature 的摘要（标题、状态、人员、当前切片 / 步骤、AC / 待定 / 风险、“点击展开”）；鼠标移到摘要上不消失；悬停 5 秒后锁定：右下角 14 px 环走满，锁定后指针离开整窗、移到别的楼段都不关、不切段；Esc、摘要右上角 ×、点击彩带或摘要展开时解除；锁定前移开就关。悬停不改变窗口尺寸；reduced-motion 下环不转，5 秒后仍锁定。
- WINDOW-12：点楼段 / 小人 / 灯 / 气泡 / 办公室 / 设计师打开对应卡片，再点同一个关掉；卡片占窗口左边一直留着的 300 CSS px 卡片位，开卡片、切卡片、关卡片都不改窗口尺寸，右缘和楼体不动（卡片底色不透明、入场只滑不淡；透明窗口改尺寸会闪一帧桌面）；卡片外透明区仍穿透；在线 pi 一级 / 二级会话出现控制区（暂停、继续、立即中断、建议输入）和待答 ask 的决策入口，只读来源不出现控制按钮。决策卡显示问题、背景、选项、自定义答案和取消；回答 / 取消受理后等 `ask_resolved`，卡关闭后可从对应小人卡重开；对应 ask 结束或会话离线时关闭。卡片开着时指针离开整窗立即关闭；指针留在窗内就保持；指针本来就在窗外时自动打开的决策卡保留，直到指针进出一次或点 × / Esc；对应楼段或办公室从快照消失时直接关它的卡。小人卡的状态只在头部显示；下面有一段最多 4–5 句的“现在”概况（等你时是问题原文，在干时是最近回复 / 思考）；会话 ID 只留头尾；不显示归属证据；最近动作最多 4 条，每条单行，时间靠右不换行；最近动作下面显示最多 10 条模型轨迹，每条标出提示 / 回复 / 思考 / 工具 / 结果 / 模型 / 压缩 / 报错；轨迹和概况都单行或短段省略，Markdown 标记和多余内容不外露；只读时说明原因。
- WINDOW-13：窗口出现在任务栏；齿轮菜单和托盘菜单按显示 / 位置 / 主题 / 行为分成四组二级菜单（快照里有两处以上工地时，位置和主题之间多一组“工地”：自动跟随和每个工地一项，勾选当前钉住的那个；某个工地上有人在等它回话时，那一项显示“<工地名> · 等你 N”），诊断和退出单列在分隔线下面；齿轮菜单点击或指针停留 120 ms 展开二级菜单（换组重新计时），指针离开整张菜单只收二级菜单，Esc 先收二级菜单再关整张菜单；二级菜单上下挪动或滚动，不出窗口；菜单开着时整窗都算“在窗内”，停在二级菜单上不会自动收起；托盘菜单是原生二级菜单；隐藏后能从托盘或任务栏恢复；左键显示 / 收起。
- WINDOW-15：启动和运行中接上 / 拔掉显示器、改变主屏或缩放时，窗口按目标屏的工作区重新贴右缘、垂直居中，画布按新设备像素重画；拔掉选定屏回主屏；窗口可拖到任意屏幕。“附着到右侧屏幕”贴到当前屏右边最近的显示器；没有右侧屏时贴当前屏右缘。
- WINDOW-16：半透明打开时，指针在窗口内容区矩形内任意位置（含空楼层和透明天空）为 100%，离开内容区才回 42%，不改穿透；没开卡片、没开菜单时左边空着的 300 CSS px 卡片位不算内容区，开着卡片或菜单时整窗都算；等待灯约 800 ms 闪一次，暗态保留 55% 亮度；勿扰压掉橙点和闪烁，暂停动画只停闪烁。
- WINDOW-18：托盘和窗内菜单有贴边隐藏、半透明、等待橙点、演示、勿扰、暂停动画和诊断；等待橙点由主进程按快照的等你状态维护；演示隐藏气泡、卡片对话文字及决策卡的问题 / 背景 / 选项并显示“演示”角标；诊断列出来源、坏行、未知记录和解析问题，显示前脱敏。

## 楼体与内容

- WINDOW-4：楼段自下而上按配置叠放，没有意图卡时按 SITE-7 的会话待办叠放；楼段名、楼层、当前切片步骤格、未完成切片虚线、脚手架、材质、crown、篷布和地面按 design 4.2 绘制，屋顶、底层和施工件按造型与施工阶段画（见 WINDOW-30、WINDOW-31）；楼体第一层固定画成实体，脚手架从第二层起；楼段名、待办文字和篷布文字显示前脱敏。
- WINDOW-5：意图卡读不出、没有切片或一个工地都没有时分别显示“图纸读不出”“图纸未拆切片”或空工地（地面、设计师和底栏都在，没有楼体），不崩溃，不出现旧模型字段。
- WINDOW-6：层高固定为可用楼体高度的十分之一；快照新增 / 删除楼层时楼体从底部往上长或缩，不足十层时层高不变；总层数超过十层才按比例收，楼层一起变薄。底部图例和灯仍固定可见。
  - 例：一个三层的工地加两层切片，五层的高度是三层的高度加两层同样的层高，不重算层高。
  - 证明：`tests/app/layout.test.ts` 中的 "WINDOW-6 …"、"增加切片后所有楼层一起变薄…"
- WINDOW-7：工人站在所在切片或待办层；气泡在该工人上一层的楼内，最多两行，细引线连到小人，不盖当前切片的格子；默认只常显等你 / 出错 / 停工的气泡；点击气泡开小人卡。
- WINDOW-8：底栏第一行是 5 色图例且只有一行；第二行是全部工地里可见会话的灯，按“等你 > 出错 > 停工 > 在干 > 空闲”排序（同状态的按等待 / 停工开始时间，再按工地），只读空心，一排最多 6 盏、2× 下每盏 24×24 CSS，多出来的显示 `+N`，不换行；等待灯闪烁。
  - 例：两个工地各有一个等你的会话，当前工地只有一个时，底栏仍出现两盏等待灯。
  - 证明：`tests/app/footer.test.ts` 和 `tests/app/layout.test.ts` 中的 "WINDOW-8 …"
- WINDOW-9：2× 下楼段名至少 12 CSS px，楼层号至少 10，气泡和图例至少 10，卡片正文至少 13，摘要正文至少 12；不截断关键文字。
- WINDOW-17：快照里消失的工人从原楼层水平走到窗口右缘并淡出约 900 ms；同层还在的人保持原位，新来的工人避让，不重叠。
- WINDOW-19：楼体只画当前工地的会话；灯和等你清单画全部工地。三处都只算最近 6 小时有动静的等待 / 空闲会话；更早的等待 / 空闲仍留在快照和诊断里，但不进楼体、灯和清单，托盘等待橙点也按可见会话算。
- WINDOW-20：等你清单列全部工地的等待项，先“现在”后“历史”，各自按等待开始时间从早到晚；每行带工地名，超过 24 小时的进“历史”。
  - 例：两个工地各有一个等你的会话，清单里两行，各自带工地名，等得久的在前。
  - 证明：`tests/app/cards.test.ts` 中的 "WINDOW-20 …"
- WINDOW-21：底栏灯里属于别的工地的会话被点中时，只打开那个小人的卡（卡上标工地名），当前工地不切换；这张卡只在它自己的工地里该小人从快照消失（或那个工地消失）时关闭，别的工地的更新不影响它。
  - 演示：当前画的是工地 A，点工地 B 的等待灯，打开的是 B 的小人卡、楼体仍是 A；B 里这个会话离场后卡关闭。
  - 证明：`tests/app/cards.test.ts` 中的 "WINDOW-21 …"

- WINDOW-30：`settings.json` 的顶层 `style` 取 `tower`（塔楼，默认）、`factory`（厂房）或 `storefront`（临街店），决定各 feature 的默认造型；`features[].style` 覆盖它，同一个 feature 用同一种造型。造型作用于三处：`placement=band` 的楼段、`placement=crown` 的穹顶和它在楼里的楼层、`placement=office` 的办公室；crown 楼段的楼层跟造型画颜色和窗型，但不画屋顶和阶段件（它上面有自己的穹顶）。顶层值无效时整套回默认并在诊断里说明；`features` 里任一 `style` 无效按 `features` 无效处理；旧配置没有该键时按 `tower` 读，不迁移文件；窗内设置面板可改顶层 `style`（见 WINDOW-27），不编辑 `features[].style`，保存其他设置时顶层和 `features[].style` 原样写回。
  - 例：`"style": "factory"` 且没有 feature 覆盖 → 每个 feature 按自己的 placement 画成厂房（band 楼段 / crown 穹顶 / office 办公室）；给 data-layer 写 `"style": "storefront"` → 只有 data-layer 是临街店。

- WINDOW-31：施工阶段由该楼段工作项的完成比例决定：有意图卡时按切片 `done / total`，没有意图卡时按会话待办的 `completed / total`；`done = 0` 是围挡，`0 < done / total < 0.5` 是地基，`0.5 ≤ done / total < 1` 是主体，`done = total` 是竣工；没有工作项是围挡，矮楼是竣工。阶段作用于 `placement=band` 的楼段、crown 的穹顶和 office 的办公室；crown 楼段的楼层本身不画阶段件；篷布楼段只画篷布，不画造型件和阶段件。塔吊全楼只有一台，立在自下而上最高的主体阶段楼段上；crown 和 office 不立塔吊。
  - 例：三段切片、完成 0 / 1 / 2 / 3 段时，依次是围挡、地基、主体、竣工；两个楼段都在主体时，只有上面那段的右缘有塔吊。

## 数据与实时

- WINDOW-14：App 通过 SiteEngine 读会话库和每个工地自己的 specs，快照最多每 250 ms 推一次；楼体、灯、气泡、已打开的卡片和摘要跟着更新，不自动展开（新决策例外见 WINDOW-10）、不抢焦点；普通更新不关卡片，只有对应 worker、楼段或办公室离开快照时才关它的卡。

## 提醒

- WINDOW-22：新来的决策提问且窗口没有焦点时弹一条系统通知，标题带工地名、正文是脱敏后按码点截断的问题，点击通知聚焦窗口；窗口有焦点或窗口还没建好时只登记不弹（之后失焦也不补弹）；勿扰不弹，演示模式的正文是占位文字。同一个 askId 只弹一次：它一直挂在列表里不会因为过了多久再弹；从列表里消失（断线或结束）的那一时刻起算，一小时内重发也不再弹（休眠很久之后先看到断线、马上重连，也只算消失了一瞬）。
  - 例：窗口被别的窗口盖住时来了一条提问，桌面弹出"等你回答 · 购物车 / 用哪个方案？"；点它，窗口到前台并拿到焦点。
  - 证明：`tests/app/notify.test.ts` 中的 "WINDOW-22 …"；系统通知本身见 [design.md](../design.md) 第 9 节的人工验收步骤

- WINDOW-25：窗口没有焦点时，某个会话第一次进入"等你""停住""断线且暂停"这三种状态各弹一条通知；状态持续不重复弹，解除后再进入重新弹（断线按"上一轮还连着、这一轮不在了"判断）；有悬着决策的会话不算"等你"，决策结束后也不补弹；有焦点、勿扰、演示模式的处理与 WINDOW-22 一致。
  - 例：某个 agent 停住时弹"停住了 · 购物车 / 中途断掉了"；它继续干活再停住，会再弹一次。
  - 证明：`tests/app/notify.test.ts` 中的 "WINDOW-25 …"；系统通知本身见 [design.md](../design.md) 第 9 节的人工验收步骤

## 等你清单

- WINDOW-28：等你清单在"现在""历史"之后有"意图卡里的待定"一栏，每行一条待定（工地名 + "楼段 · 文字"），文字经脱敏，演示模式下这一栏只显示条数、不显示文字；只取意图卡"待定"一节里的列表项，最多 20 条（矮楼、篷布楼段和办公室的待定都算）。
  - 例：某工地某个 `spec.md` 的"待定"写着"先定鉴权方式"，清单里出现 `<工地> · 数据层 · 先定鉴权方式`。
  - 证明：`tests/app/cards.test.ts` 中的 "WINDOW-28 …"、`tests/main/intent-card.test.ts` 的解析断言

- WINDOW-29：等你清单在"意图卡里的待定"之后有"工地的待做"一栏，每行一条（工地名 + 文字），只取被监视仓库 `specs/backlog.md` 里以 `- ` 开头的行，最多 20 条；文字经脱敏，演示模式下只显示条数。
  - 例：某工地的 `specs/backlog.md` 写着 `- 加亮色主题`，清单里出现 `<工地> · 加亮色主题`。
  - 证明：`tests/main/intent-card.test.ts` 中 WINDOW-29 的读取断言、`tests/app/cards.test.ts` 中的 "WINDOW-29 …"

## 设置

- WINDOW-27：齿轮菜单和托盘菜单有「设置…」，打开窗内设置面板；面板可改配色、开机自启、三条阈值、默认造型（`tower` / `factory` / `storefront`）、额外固定的工地列表（一行一个 `路径`，改名字写 `路径 = "名字"`，这一栏显示文件原文不脱敏）；保存时按与读取相同的规则校验，有错的项逐条说明且不写文件、不改运行状态；保存成功后写入 `settings.json` 并当场生效（阈值的变化通过重开引擎生效）。面板不编辑 `features[].style`，保存时原样保留。
  - 三条阈值要是大于 0 的数字，且停工分钟必须大于空闲分钟；面板和读文件用同一条判断：面板不接受的写不进去，读文件时不接受的（含停工不大于空闲）整套回到默认配置并在诊断里说明是哪一条。
  - 例：点开设置写 `空闲 0`，点保存 → 面板显示"空闲分钟要是大于 0 的数字"，文件没变；改成 5 保存 → 文件里 `thresholds.idleMinutes` 变成 5。工地写一行相对路径 → 报"工地要写绝对路径：…"，文件不变。点「厂房」保存 → 文件里 `style` 变成 `factory`，楼段和穹顶当场换成厂房。
  - 证明：`tests/app/settings-form.test.ts`、`tests/main/settings.test.ts` 中的 "WINDOW-27 …"、`tests/app/menu.test.ts` 的单列项；面板观感见 [design.md](../design.md) 第 9 节的人工验收步骤

## 外观

- WINDOW-26：App 有两套配色，`settings.json` 的 `theme` 为 `night`（默认）或 `day`，决定启动时的配色；齿轮菜单和托盘菜单的「主题」一组可当场切换（单选，`night` / `day`）。两套配色的区别只在外壳（面板、楼体剪影、边框、文字、地面），材质和状态色共用。
  - 例：写 `"theme": "day"` 重启，整座工地是亮的；菜单里点「夜色」，窗口立刻变回暗的。
  - 证明：`tests/app/theme.test.ts`、`tests/main/settings.test.ts` 里的 "WINDOW-26 …"、`tests/app/menu.test.ts` 的「主题」一组；观感见 [design.md](../design.md) 第 9 节的人工验收步骤

## 快捷键

- WINDOW-23：`Ctrl/⌘+Alt+S` 显示 / 收起窗口；`Ctrl/⌘+Alt+P` 暂停或继续当前工地上所有能控制的会话（有人暂停就全部继续，否则全部暂停）；注册失败不影响 App，退出时注销。
  - 例：在终端里按一下 `Ctrl+Alt+P`，当前工地的 agent 在下一次工具调用时停住；再按一下继续。
  - 证明：`tests/app/shortcuts.test.ts`；真实按键、注册失败隔离和退出后释放键位见 [design.md](../design.md) 第 9 节的人工验收步骤

## 启动

- WINDOW-24：`settings.json` 的 `autostart` 为 `true` 时，App 启动后把自己注册成开机自启；为 `false`（默认）时撤销。注册失败不影响 App 运行。
  - 例：写 `"autostart": true`，重启电脑后窗口自己出现；改写 `false` 后再重启就不再出现。
